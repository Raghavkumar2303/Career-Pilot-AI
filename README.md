## 📌 Overview

Career Pilot AI is an intelligent career guidance assistant that recommends suitable career paths based on a user's skills, interests, education, and problem-solving abilities.

The project is developed using **IBM watsonx.ai Agent Lab** with the **Meta Llama 3.3 70B Instruct** model and is deployed on **IBM Cloud**.

---

## 🎯 Problem Statement

Many students and professionals struggle to identify suitable career opportunities based on their skill sets.

Career Pilot AI helps users by analyzing their skills and recommending the most appropriate job roles along with brief explanations.
